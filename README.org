#+title: Fly & You
#+options: toc:nil num:nil

A native Bevy + bevy-egui drawing platformer. You cannot control the tiny black fly directly. The fly is a fly.

Uses [[https://male-cns.janelia.org/]]

* Play

With the local dependencies prepared:

#+begin_src sh
./scripts/run.sh
#+end_src

Once loading finishes, press *Enter* to start the tutorial. The opening screen waits until you're ready to record; *Replay intro* returns to it for another take.

Six puzzles are available in the toolbox level chooser. After a win, press *N* for the next level. Later levels start paused; *Space* runs or pauses, and *R* resets the current level.
