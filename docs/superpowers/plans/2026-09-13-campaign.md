# Fly & You campaign implementation plan

**Goal:** Implement the five approved puzzles after First Flight, in the approved order.
**Architecture:** Immutable Rust level descriptions supply geometry, Ground zones, buttons, gates, and swatters. World snapshots carry the level index and button state; the existing neural decision boundary stays unchanged. The existing toolbox supplies level selection, a short rule, and progression.
**Tech stack:** Rust, Bevy 0.19.1, bevy-egui 0.42.0; existing Python neural worker.
**Spec:** Approved six-level storyboard in `fly-puzzle-layouts.html` (conversation visualization). Grid dimensions may be adjusted for the actual 12 × 16 body.

Constraints: Keep Level 1's complete tutorial. No elapsed-time failure. Space pauses hazards. One new mechanic at a time. Keep actual grayscale-first perspective and real brain activity. Work inline; user commits.

- [x] World mechanics: add `levels.rs`, `World::level(index)`, `level_spec()`, persistent `button_pressed`, `swatter_phase()`, Ground-zone validation, and shared-zone exclusivity. Test that a bridge cannot exist in both shared zones, including undo; body contact opens the gate; seeded plugs erase and reset; swatter contact kills only in its active phase; waiting never times out; checkpoints validate against their own immutable level.
- [x] Geometry and sensory integration: translate the existing flag by the goal offset; render every level's hazards, button, gate, and swatter in both canonical and eye views. UI-only dashed Ground-zone annotations stay out of observations. Exercise actual edits and physics through a complete route in each level and check grayscale-first observations.
- [x] Desktop progression: add a level chooser and next-level action in the existing toolbox. Switch/reset at the existing safe restore boundary with the initial brain checkpoint and a fresh epoch; reset stays on the current level, bookmarks restore their own level. Later levels start paused with a short rule; Level 1 alone uses the animated intro. Test coordinator reset rejection of old actions and level restoration.
- [x] Verify and document: run workspace tests, formatting and diff checks; build the app; native-check selection, visible level mechanics, and real-worker motion. Update the public level documentation and record the limits of scripted versus neural play checks. No commit or broad staging.

Approved order and rule:
1. First Flight — existing tutorial.
2. Borrowed Ground — two gaps, one shared Ground patch; erase the old bridge to reuse it.
3. Touch and Go — body-operated button A permanently opens gate A, then return left.
4. Pull the Rug — cross an erasable floor plug to A, return and remove the plug to drop to the exit route.
5. Swat Team — a cycling swatter, with a removable stopping-wall zone before it.
6. The Long Way Home — combine the shared bridge, button, erasable plug, drop, and return route; no new rule.
